# SOATVELASQUEZ.COM — Velasquez Corredores de Seguros

Plataforma web de emisión digital 24/7 de Seguro Obligatorio de Accidentes de Tránsito (SOAT) y corretaje integral de seguros con respaldo formal en Pucallpa, Ucayali, Perú.

## Características Principales

- **Cotizador Digital de SOAT 24/7:** Tarifario referencial por categoría de vehículo (Autos particulares, Mototaxis, Pick Up, Furgonetas, Motos y Camiones pesados).
- **Validación de Placa Vehicular:** Validación y normalización automática del formato alfanumérico según la normativa peruana.
- **Integración Inmediata con WhatsApp:** Generación de enlaces preformateados para emisión y entrega inmediata de certificados electrónicos.
- **Trámites de Circulación:** Asesoría en obtención, renovación y duplicado de tarjetas de circulación y afiliación en Pucallpa.
- **Corretaje Integral de Seguros:** Líneas de Seguro Vehicular Todo Riesgo, Salud, Hogar, SCTR y Pólizas Empresariales.
- **Cumplimiento Normativo Peruano:** Acceso al portal de verificación de APESEG, Libro de Reclamaciones Virtual (Ley N° 29571) y Protección de Datos Personales (Ley N° 29733).

## Stack Tecnológico

- **React 19**
- **TypeScript 7**
- **Vite 8**
- **Tailwind CSS v4**
- **Motion 12**
- **Lucide Icons**

## Instalación y Ejecución

Para iniciar el entorno de desarrollo local:

```bash
# Instalación de dependencias
npm install

# Iniciar servidor de desarrollo en http://localhost:3000
npm run dev

# Compilar para producción
npm run build

# Previsualizar la compilación de producción
npm run preview
```
